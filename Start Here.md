# GPU Builder

Open [[Design Plan]] for the planned interaction and teaching scope. Application source is in `app/`.

Run with Node.js 24+:

```bash
cd '/home/earth/Work/GPU Builder/app'
npm start
```

Open http://localhost:4180. Browser-local progress stays on that browser; export JSON to transfer a project. No account or cloud connection is required.

Run `npm test` for model checks. The static app can also be served by any ordinary static web server. It is separate from the Code Zen Studios production site.
